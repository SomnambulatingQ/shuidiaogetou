# 水调歌头 · 明月几时有 | 课后自主学习页

**在线访问：<https://somnambulatingq.github.io/shuidiaogetou/>**（GitHub Pages，公开、免费、无需本机开机）

一个纯静态的教学演示页，复刻「希沃 Bloom 教学工具分享页」里那套《水调歌头》课后自学课件的结构与交互：宣纸底、水墨远山、朱砂点缀，五个学习模块用顶部标签切换。

无任何依赖、无构建步骤、可离线打开。

## 打开方式

**方式一：直接双击**

打开 `index.html` 即可（CSS/JS 都是普通文件，`file://` 下可以正常工作）。

**方式二：本地静态服务**（推荐，便于分享与手机同网访问）

```bash
# 在本目录执行
python -m http.server 8099
```

然后访问 <http://127.0.0.1:8099/>。

> 注意：`127.0.0.1` 只对本机有效，发给别人是打不开的。

## 分享给别人

| 方式 | 适合场景 | 做法 |
| --- | --- | --- |
| **单文件 HTML** | 微信/QQ/邮件发给朋友，对方双击就看 | 发 `水调歌头-课后自主学习.html`（CSS、JS 已内联，无需联网） |
| **局域网地址** | 同一個 Wi-Fi 下的手机、平板、教室电脑 | 服务启动时用 `--bind 0.0.0.0`，把 `http://<你的内网IP>:8099/` 给对方 |
| **公网临时链接** | 朋友在异地，想直接点开 | `cloudflared tunnel --url http://127.0.0.1:8099`，把生成的 `https://xxx.trycloudflare.com` 发过去 |

局域网查看本机内网 IP：

```powershell
ipconfig | Select-String "IPv4"
```

若对方打不开局域网地址，多半是 Windows 防火墙拦了 Python 的入站连接，在「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里放行即可（或首次启动时点「允许访问」）。

## 细节

- **深链接**：`index.html#chars`、`#notes`、`#translation`、`#theme` 可直接打开对应模块。
- **键盘**：标签栏支持 ← → Home End 切换，所有卡片和词条均可 Tab 聚焦、Enter 触发。
- **阅读进度**：顶部细进度条；右下角「回到顶部」按钮。
- **响应式**：≥ 900px 三列卡片，≤ 900px 两列，≤ 720px 单列对照；标签栏可横向滑动。
- **打印**：`Ctrl/Cmd + P` 会展开全部模块、展开注释、显示卡片背面，可直接导出 PDF 学案。
- **无脚本兜底**：JS 失效时内容依然全部可见（进场动画只在 `html.js` 下生效）。
- **动效偏好**：尊重 `prefers-reduced-motion`。

## 想改成自己的课文

1. `index.html` 里按注释分区（`<!-- 壹 · 原文 -->` 等）替换文本；
2. 字音卡片的数量随意增减，`.flip` 结构照抄即可；
3. 注释词条同理，`.acc` 是一组，`data-acc` 的「全部展开 / 收起」自动适配；
4. 配色改 `styles.css` 顶部的 `:root`：`--paper` 纸色、`--ink` 墨色、`--red` 朱砂、`--gold` 赭石。
